# WLLPP Wallpaper Updater

Централизованное обновление обоев рабочего стола Windows через GitHub.

От Саши отличается сама схема, плюсом нет открытого пароля. Я чет ссусь за него

## Возможности

- Каждый час (и при старте винды) скачивает wallpaper.png из ветки main.

- Применяет обои после часовой проверки и при входе зарегистрированного пользователя. Пятиминутных проверок больше нет.

- Сам регистрирует задачи для существующих и новых обычных профилей Windows при часовой проверке. После первого входа новый профиль будет обнаружен при ближайшем запуске загрузчика.

- Проверяет, что файл — трушный PNG, сравнивает SHA-256 и сохраняет старые обои, если загрузка не удалась.

- Делает отдельную BMP-копию для каждого пользователя, чтобы Windows не показывал закешированную картинку.

- Ставится и переставляется в один клик. 


## Установка

1. Откройте репозиторий → Code → Download ZIP.

2. Распакуйте архив (не запускайте файлы прямо из ZIP).

3. Запустите INSTALL.bat c правами админа.

4. Дождитесь первой загрузки обоев.

## Как обновить обои

Замените `wallpaper.png` в ветке main и сделайте commit. Требования к картинке: настоящий PNG (не переименованный жпег).
Потом все компы подхватят новую картинку при следующем часовом запуске, применение запустится сразу после загрузки. **Без сети** остаются прежние обои. Переустанавливать ничего не нужно.

При изменении самого кода скачайте свежий ZIP и повторно запустите `INSTALL.bat`: старые задачи WLLPP будут заменены. Скрипты не обновляются автоматически с GitHub.

Форкни мою репу, и в `DownloadWallpaper.ps1` замени $url = 'https://raw.githubusercontent.com/USERNAME/wallpaperUpdate/main/wallpaper.png'. Username - логин твоего акка, у меня Cvesti.


Порядок действий
1. Сделать Fork моего репозитория.
2. Изменить переменную $url в DownloadWallpaper.ps1.
3. Сохранить изменения через Commit changes.
4. Загрузить свою картинку wallpaper.png.
5. Скачать ZIP своего репозитория.
6. Распаковать архив и запустить INSTALL.bat.

## Диагностика

Файлы устанавливаются в `C:\Program Files\WLLPP`.

| Журнал | Назначение |
|---|---|
| `C:\Program Files\WLLPP\Download.log` | Загрузка, SHA-256, ошибки и запросы применения |
| `C:\Program Files\WLLPP\Provision.log` | Регистрация задач пользователей |
| `%LOCALAPPDATA%\WLLPP_Update.log` | Применение обоев, SID и номер сеанса текущего пользователя |

В планировщике Windows одна периодическая задача `WLLPP_Wallpaper_Download` и задачи `WLLPP_Wallpaper_Apply_<SID>` для пользователей. Отдельная задача регистрации больше не нужна.

Ручная проверка загрузки (PowerShell от администратора):

```powershell
Start-ScheduledTask -TaskName 'WLLPP_Wallpaper_Download'
```

Ожидаемый интервал: Download — PT1H (1 час). Apply запускается при входе или по запросу загрузчика, без периодического расписания.

## Системные требования

- Windows 10/11, интернет и доступ к `raw.githubusercontent.com` из контекста SYSTEM.
- Права администратора для установки. Политики организации не должны блокировать PowerShell, планировщик или смену обоев.
- Выключенные и спящие ПК обновятся после возобновления работы и доступности инетика.

Перед массовой установкой проверьте работу на одном ПК под администратором и обычным пользователем. Это оч важно, так как могут вылезти проблемы. Проверял все на неттопе MSI
