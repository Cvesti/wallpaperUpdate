# WLLPP Wallpaper Updater

Автоматическая смена обоев Windows на нескольких компьютерах через GitHub.

## Как установить

1. [Скачайте архив проекта](https://github.com/Cvesti/wallpaperUpdate/archive/refs/heads/main.zip) или нажмите **Code → Download ZIP**.
2. Распакуйте архив в любую папку. Не запускайте установщик прямо из ZIP.
3. Откройте распакованную папку и дважды нажмите `INSTALL.bat`.
4. В окне контроля учётных записей Windows нажмите **Да**. Если потребуется, введите пароль администратора.
5. Дождитесь сообщения об установке. Первая загрузка обоев запустится автоматически. Если картинка не появится сразу, проверьте её через 5 минут и посмотрите журнал загрузки.

Установку нужно выполнить один раз на каждом компьютере. Вручную запускать файлы `.ps1` или менять политику PowerShell не нужно.

## Как поменять обои

1. Подготовьте новое изображение в формате PNG.
2. Замените `wallpaper.png` в ветке `main` на GitHub (имя файла должно остаться прежним).
3. Нажмите **Commit changes**.

Компьютеры проверяют GitHub каждые 60 минут и при запуске Windows. После загрузки программа запрашивает смену обоев у вошедших пользователей; дополнительно выполняется проверка каждые 5 минут и при входе. Новые профили обнаруживаются автоматически. При отсутствии интернета сохраняются предыдущие обои.

Не переименовывайте JPEG или WebP в PNG: изображение должно быть настоящим PNG, не больше 30 МБ и 40 млн пикселей.

## Как использовать свой репозиторий

Создайте публичный репозиторий на GitHub, скопируйте в него все файлы проекта и загрузите свой `wallpaper.png`. В `DownloadWallpaper.ps1` измените одну строку:

```powershell
$url = 'https://raw.githubusercontent.com/USERNAME/REPOSITORY/main/wallpaper.png'
```

Подставьте имя пользователя, репозитория и ветки. После изменения ссылки скачайте архив своего репозитория и запустите `INSTALL.bat`. Остальные скрипты менять не нужно.

## Файлы проекта

| Файл | Назначение |
|---|---|
| `INSTALL.bat` | Запуск установки |
| `install.ps1` | Копирование файлов и настройка задач |
| `DownloadWallpaper.ps1` | Загрузка и конвертация обоев |
| `ApplyWallpaper.ps1` | Смена обоев пользователя |
| `ProvisionUsers.ps1` | Регистрация пользователей |
| `wallpaper.png` | Изображение обоев |

## Если обои не обновляются

Файлы устанавливаются в `C:\Program Files\WLLPP` (или соответствующий системный каталог Program Files).

Журналы:

- `C:\Program Files\WLLPP\Download.log` — скачивание.
- `C:\Program Files\WLLPP\Provision.log` — регистрация пользователей.
- `%LOCALAPPDATA%\WLLPP_Update.log` — смена обоев текущего пользователя.

Чтобы проверить загрузку прямо сейчас, откройте PowerShell от администратора и выполните:

```powershell
Start-ScheduledTask -TaskName 'WLLPP_Wallpaper_Download'
```

## Переустановка

Если изменился код программы, скачайте свежий архив, распакуйте его и снова запустите `INSTALL.bat`. Старые задачи будут заменены. Папка прежней версии `C:\PRJ_Notification` не удаляется. Для обычной смены картинки переустановка не требуется.

## Требования

Windows 10/11, Windows PowerShell 5.1, интернет, работающий планировщик задач и права администратора для установки. Системный аккаунт SYSTEM должен иметь доступ к raw.githubusercontent.com. Политики Windows не должны запрещать смену обоев. Проект рассчитан на обычные настольные сеансы, не на многосеансовые RDS. Перед массовой установкой проверьте работу на одном компьютере.
